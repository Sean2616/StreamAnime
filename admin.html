    Episode

    Panel ini mengelola link video saja — file videonya sendiri tidak di-upload ke sini. Google Drive sekarang untuk Player Pratinjau + Download: tempel link berbagi Drive ke kolom Link Google Drive (Player & Download) dan atur berbaginya menjadi "Siapa saja yang memiliki link" (Anyone with the link) — link itu tampil sebagai server streaming Google Drive (player pratinjau resmi Google) di halaman nonton dan menjadi tombol Download, dan Download memang hanya dari Drive (MEGA / MP4 / server lain tidak menyediakan unduhan). Untuk streaming, pakai kolom Link MEGA, Link Lainnya (MP4, .m3u8 (HLS), YouTube, Vimeo, atau link embed dari host streaming seperti VidHide, Filemoon, Filedon, VOE, Streamtape, Doodstream, MixDrop, dan Archive.org), atau kolom Server Tambahan (klik + Tambah Server, beri nama bebas dan tempel linknya). Link Drive yang ditempel ke Link Lainnya / Server Tambahan juga tidak akan tampil sebagai server streaming. Bila sebuah episode punya lebih dari satu server streaming terisi, pengunjung bisa memilih server di halaman nonton. Kosongkan kolom yang tidak dipakai.
